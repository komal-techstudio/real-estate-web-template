# Real Estate Web Template & Lead Management

A lightweight, modern, and responsive front-end web application built for real estate property showcases and client lead generation.

## 🚀 Features
- **Responsive Layout:** Optimized for mobile, tablet, and desktop screens.
- **Interactive Property Listings:** Seamless presentation of property features, images, and pricing.
- **Lead Capture Form:** Integrated inquiry form for real-time customer registration.
- **Clean Architecture:** Semantic HTML5, CSS3 styling, and modular JavaScript structure.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript
- **Integration Ready:** Webhook-compatible for CRM, automated chatbot, and sheet sync workflows.
